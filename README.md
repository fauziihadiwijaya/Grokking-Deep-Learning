# Grokking Deep Learning

A chapter-by-chapter implementation and theoretical exploration of *Grokking Deep Learning* by Andrew W. Trask.

This repository is developed as part of the **Deep Learning Enrichment Individual Assignment**, focusing on code reproduction, theoretical understanding, and practical implementation of deep learning concepts.

## 📌 Project Overview

The purpose of this repository is to strengthen the understanding of deep learning through hands-on implementation and theoretical exploration based on the book *Grokking Deep Learning*.

Each chapter is documented through Jupyter Notebooks containing:

* **Code Reproduction:** Implementing the concepts and algorithms introduced in the book.
* **Theoretical Deep-Dive:** Explaining the underlying mathematical and conceptual foundations.
* **Code Explanation:** Describing the purpose and functionality of important code sections.
* **Visualization:** Presenting relevant plots or diagrams to support conceptual understanding.
* **Chapter Summary:** Highlighting the key takeaways and lessons learned.

## 🎯 Objectives

1. Understand the fundamental principles of deep learning.
2. Reproduce implementations of neural networks and learning algorithms.
3. Explain the mathematical foundations behind each implementation.
4. Connect theoretical concepts with practical computational results.
5. Develop a structured learning resource for deep learning.

## 🚀 Getting Started

### 1. Clone the Repository

```bash

```

### 2. Navigate to the Repository

```bash

```

### 3. Install Dependencies

```bash

```

### 4. Open the Notebooks

The notebooks can be opened using Jupyter Notebook or Google Colab.
